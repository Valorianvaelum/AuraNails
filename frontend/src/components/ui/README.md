# Componentes UI

Primitivas visuales propias de AuraNails, organizadas con el patrón de shadcn/ui.

Reglas:

- reutilizar tokens semánticos del proyecto;
- no introducir colores hexadecimales nuevos salvo estados documentados;
- preservar foco visible, estados disabled y targets táctiles;
- no incluir lógica de negocio;
- preferir composición antes que variantes específicas por pantalla;
- componentes complejos de overlay deberán usar primitivas accesibles robustas.
